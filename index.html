Stage 1 — Quick Lesson

What is Hi-Lo?

Hi-Lo assigns every card one of three values. You start at 0 and update the Running Count as cards appear.

+1
2, 3, 4, 5, 6
0
7, 8, 9
−1
10, J, Q, K, A
Example:
5 = +1
8 = 0
K = −1

A complete 52-card deck is balanced. If every card is counted correctly, the final count returns to 0.

Stage 4 — Quick Lesson

Cancellation

A +1 and a −1 cancel each other. This lets you process several cards faster.

Examples:
5 + K = 0
3 + A = 0
4 + 6 + Q = +1

Look for pairs and small groups that simplify to 0.

Stage 5 — Quick Lesson

True Count

In multi-deck games, the Running Count must be adjusted for the number of decks remaining.

Formula:
True Count = Running Count ÷ Decks Remaining

Example:
+8 ÷ 4 decks = +2

This stage starts with clean whole-number examples so you can learn the calculation clearly.
